### 数据类

```kotlin
data class PanelBox(x: Float, y: Float, w: Float, h: Float, order: Int, conf: Float) // 归一化 0~1
data class PanelPageResult(boxes: List<PanelBox>, pageConf: Float, fallback: Boolean)
```

### 管线（PanelTunables 全参数在此，调优只动这个 object）

```
analyze(gray:IntArray, w, h, rtl):
 1. binarize: Otsu(256直方图) → 墨水=gray<thr；白占比∉[0.15,0.85] → 高斯自适应(blk31,C=5，积分图)；
    仍不健康 → 反转 Otsu（黑底白字页）；三者选白占比最健康的
 2. close: 方核 k=max(3, round(0.003*min(w,h)))，可分离膨胀+腐蚀
 3. connectedComponents: 8连通 union-find 行扫描 → label bbox+area
 4. candidates: bbox 宽高均≥页面/8 且面积≥2%页 → 候选；否则入碎片池（bbox 面积≥0.05%页才留）
 5. 碎片归组: 碎片 bbox 各向外扩 1.2%·maxSide，相交 union-find 合并，并集≥1/8 才成候选
 6. 包含合并: area(∩)/area(小) > 0.5 → 弃小（气泡/装饰）
 7. 去重叠: ∩>0.9·小 → 弃小；否则按重叠较小的轴把边收到共享边界中点
 8. 中缝外扩(保守): 每边向同轴邻居扩 min(gap*0.6, 6%页)，扩后不得与他框相交(<0.4%页呼吸缝)
 9. NMS: IoU 0.4 贪心按面积
10. 整页规则: 0 框 → fallback；唯一框面积≥85% → 该框即整页（跨页大图保护，不降级）
11. 顺序: 行聚类(行容差=0.5×中位格高, 垂直重叠≥50%归同行) → 行按顶 y 排(容差 6%页高内视为同行冲突
    走修正回路) → 行内按 x（RTL 降序）→ 修正回路: 上方格+同向侧格必须在前，违者前移，迭代≤n²
12. 置信度: pageConf = 0.45·coverage + 0.20·gutterCV(中缝宽变异<0.35 满分) + 0.20·count(1..12) + 0.15·aspect(0.15~6.5)
    coverage∈[0.65,0.98] 满分线性衰减；pageConf<0.5 或 0 框 → fallback=true（整页单格）
输出: boxes 已按 order 排列；坐标归一化
```

### PanelDetector（Bitmap 包装）

- `suspend fun detect(src: Bitmap, rtl: Boolean): PanelPageResult`（Dispatchers.Default）
- 长边 >960 先 createScaledBitmap 缩样，getPixels 提取，缩样图即 recycle；灰度 0.299/0.587/0.114
- 结果缓存：`PanelResultCache`（object，LruCache<String, PanelPageResult> 512 条，key="$treePath#$pageIndex"）；命中直接回，换书 `clearBook(treePath)`
- logcat: `PanelDetector` tag 输出耗时/框数/置信度（真机排查入口）

### PanelGuideOverlay（自定义 View，一期交互契约）

```
begin(Session): bitmapProvider:() -> Bitmap?, pageCount:Int, rtl, eink,
  nav: ViewerNavigation(点按分区), goToPage:(Int)->Unit, currentPage:() -> Int, onExit:() -> Unit
end(); onHostPageChanged(page:Int)
内部: 自己的 CoroutineScope(Default+SupervisorJob)，页→结果内存表，panelIdx，pendingPanel(跨页落点)
onTouchEvent: 点击→nav.getAction(fx,fy)：PREV=上一格 NEXT=下一格 MENU=退出；水平位移>64dp=滑动切格(左滑=下一，与 pager 惯例一致)
next(): 末格→currentPage<pageCount-1 ? goToPage(+1)+pendingPanel=0 : onExit()
prev(): 首格→currentPage>0 ? goToPage(-1)+pendingPanel=LAST : 无动作
onHostPageChanged: 取缓存/异步检测该页；panelIdx=pendingPanel?:0，pendingPanel 用后即清
onDraw: ①整页位图 fit-center 铺底 ②四矩形压暗当前格以外(黑 55%)
  ③当前格裁切亮显：srcRect=box×位图尺寸 → dstRect=按视图适配居中 ④2dp 描边(#7C8CF8)
  eink: 跳②③动画，仅 3px 描边（墨水屏纪律：无大面积灰罩、无渐变）
  识别中: 沿用上一页画面+右下角小字"识别中…"，就绪后原位换（KOReader 防闪纪律）
动画: 180ms 裁切矩形插值（ValueAnimator），eink 关
```
