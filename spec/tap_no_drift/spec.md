# 需求规格：点击漫画画面漂移

- **需求ID**: REQ-006
- **标题**: 点击漫画弹出窗口时画面不漂移
- **优先级**: P1（高）
- **基线 commit**: eb2ac412
- **状态**: 待评审

## 1. 背景与问题

阅读漫画时，点击画面弹出底部工具栏和上方标题栏（chrome 显隐切换）的瞬间，漫画画面会发生一次漂移（位置/尺寸跳动），影响阅读体验。期望：弹出/收起上下窗口时画面保持不动。

## 2. 核心输入

1. 用户在阅读画面上的点击事件（触发 chrome 显隐切换）
2. 当前阅读视图的布局参数（边距、padding、chrome 占位）

## 3. 核心输出

1. 上下 chrome 的显隐状态
2. 漫画画面的渲染位置/尺寸（应保持不变）

## 4. EARS 需求

### 4.1 画面不漂移

**REQ-006-A**
WHEN 用户在阅读中点击漫画画面触发底部/上方窗口（chrome）显隐切换 THE SYSTEM SHALL 保持漫画画面的位置与尺寸不变，不产生可见的漂移或跳动。

**REQ-006-B**
WHEN chrome 由隐藏切换为显示 THE SYSTEM SHALL NOT 改变漫画内容区的有效绘制区域位置（通过 overlay 叠加而非挤占内容区来实现 chrome 显示）。

**REQ-006-C**
WHEN chrome 由显示切换为隐藏 THE SYSTEM SHALL NOT 改变漫画内容区的有效绘制区域位置。

### 4.2 约束

**REQ-006-D**
WHILE chrome 显隐切换 THE SYSTEM SHALL 保证画面锚点（当前页的缩放/平移基准）不变，不因 padding/inset 变化重新布局导致画面重定位。

**REQ-006-E**
IF 画面漂移由内容区 padding 随 chrome 显隐变化引起 THEN THE SYSTEM SHALL 改为 chrome 以悬浮 overlay 方式叠加在画面之上，不挤占内容区布局。

## 5. 验收条件

1. 点击画面弹出上下窗口时，画面无可见漂移/跳动。
2. 再次点击收起窗口时，画面同样不漂移。
3. 连续多次显隐切换，画面始终稳定。
4. 缩放/平移状态下显隐 chrome，锚点不变。

## 6. 职责边界

- 不负责 chrome 内部的功能与样式
- 不负责点击分区（PREV/NEXT/MENU）的判定逻辑
- 仅负责消除 chrome 显隐切换引起的画面位置/尺寸变化
