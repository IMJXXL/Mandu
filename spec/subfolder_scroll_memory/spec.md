# 需求规格：子文件夹滑动记忆点

- **需求ID**: REQ-007
- **标题**: 子文件夹界面滑动记忆点核实与补全
- **优先级**: P2（中）
- **基线 commit**: eb2ac412
- **状态**: 待评审

## 1. 背景与问题

首页书架返回后已有滑动记忆点。阅读器目录页签的子文件夹滚动记忆已由 `TocScrollStore` 实现（键 `bookId|当前层路径`，LRU 128，落盘 SharedPreferences）。但首页书架进入的子文件夹界面（如某文件夹 A 内含上百个文件）的滑动记忆点是否存在需要核实，若缺失则补全。

## 2. 核心输入

1. 用户在首页书架进入子文件夹的导航操作
2. 子文件夹界面的滚动位置
3. 返回/重进同一子文件夹的事件

## 3. 核心输出

1. 子文件夹界面的滚动恢复位置
2. 滚动记忆的持久化存储（跨返回/重进/进程重启）

## 4. EARS 需求

### 4.1 核实与补全

**REQ-007-A**
WHEN 实施本需求前 THE SYSTEM SHALL 先核实首页书架子文件夹界面（如文件夹 A 内含上百文件）是否已存在滑动记忆点，若已存在则仅验证其正确性，若缺失则补全。

**REQ-007-B**
WHEN 用户在子文件夹界面滚动到某位置后返回 THE SYSTEM SHALL 记住该子文件夹的滚动位置。

**REQ-007-C**
WHEN 用户再次进入同一子文件夹 THE SYSTEM SHALL 将列表恢复到上次离开时的滚动位置附近（以首个可见项 index 为准，列数/屏幕变化时误差一屏内可接受）。

**REQ-007-D**
WHILE 滚动记忆点数量累积 THE SYSTEM SHALL 设置合理上限（如 LRU 128），超限淘汰最久未访问项，不无界增长。

**REQ-007-E**
WHEN 进程重启后再次进入同一子文件夹 THE SYSTEM SHALL 仍能恢复到上次滚动位置（记忆持久化落盘）。

### 4.2 约束

**REQ-007-F**
IF 子文件夹内容在离开期间发生变化（新增/删除文件） THE SYSTEM SHALL 恢复位置以首个可见项 index 为准，不因内容变化导致越界或错乱。

**REQ-007-G**
WHEN 不同子文件夹的滚动记忆 THE SYSTEM SHALL 按文件夹身份（路径/id）独立存储，互不干扰。

## 5. 验收条件

1. 已先核实首页子文件夹界面是否有滑动记忆点（有据可查）。
2. 滚动后返回再进，落回原位附近。
3. 进程重启后仍记得。
4. 不同子文件夹记忆独立。
5. 记忆数量有上限，不无界增长。
6. 内容变化后恢复不越界/不错乱。

## 6. 职责边界

- 不负责阅读器目录页签的子文件夹记忆（已由 TocScrollStore 实现，仅核实不重复实现）
- 不负责子文件夹的内容扫描/排序逻辑
- 记忆存 index 不存像素 offset（列数/屏幕变化容差一屏内）
