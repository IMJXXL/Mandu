# 需求规格：逐格阅读始终常开

- **需求ID**: REQ-002
- **标题**: 逐格阅读始终常开
- **优先级**: P1（高）
- **基线 commit**: eb2ac412
- **状态**: 待评审

## 1. 背景与问题

当前逐格阅读（Panel-by-Panel）开关为会话级状态（`panelGuideActive`），开启后仅在当前阅读会话内生效，退出阅读或切换书籍后状态丢失，用户每次进书都要重新开启。用户期望：开启即始终开启，直到主动关闭；且开启后底栏图标不应切换成"退出逐格"文案，始终保留为该功能的统一入口。

## 2. 核心输入

1. 用户在阅读设置面板切换「逐格阅读」开关
2. 进书/切书/退出阅读/进程重启事件
3. 逐格可用性判定结果（翻页族单页 + 非竖翻/瓦片/横屏自动双页/横屏自动条漫/仿真翻页）

## 3. 核心输出

1. 逐格开关持久状态（全局，跨书跨进程保持）
2. 逐格覆盖层的挂载/卸载
3. 底栏逐格入口图标的显示状态

## 4. EARS 需求

### 4.1 开关持久化

**REQ-002-A**
WHEN 用户开启「逐格阅读」开关 THE SYSTEM SHALL 将该开启状态持久化保存，跨书、跨阅读会话、跨进程重启保持开启，直到用户主动关闭。

**REQ-002-B**
WHEN 用户关闭「逐格阅读」开关 THE SYSTEM SHALL 将该关闭状态持久化保存，后续进书不再自动进入逐格模式。

**REQ-002-C**
WHILE 逐格阅读开关处于开启状态且当前页面满足逐格可用性条件 THE SYSTEM SHALL 自动进入逐格模式，无需用户逐页或逐书手动启动。

**REQ-002-D**
WHILE 逐格阅读开关处于开启状态但当前页面/视图不满足逐格可用性条件（条漫、竖翻、瓦片、仿真翻页等） THE SYSTEM SHALL 保持开关开启但不挂载逐格覆盖层，以普通页面显示。

### 4.2 入口图标不变

**REQ-002-E**
WHILE 逐格阅读开关处于开启状态 THE SYSTEM SHALL NOT 将底栏图标文案切换为"退出逐格"，始终以该功能的统一入口形式显示（如"逐格阅读"）。

**REQ-002-F**
WHEN 用户点击逐格阅读入口 THE SYSTEM SHALL 打开逐格设置面板，在面板内通过开关控制功能的开启/关闭，而非点击入口直接切换开/关态。

### 4.3 约束

**REQ-002-G**
IF 逐格阅读开关从开启被关闭 THEN THE SYSTEM SHALL 立即卸载逐格覆盖层并恢复普通阅读显示，开关状态即时落盘。

**REQ-002-H**
WHEN 逐格阅读开关状态在阅读会话内被切换 THE SYSTEM SHALL 即时生效，无需重新进书。

## 5. 验收条件

1. 开启逐格阅读后退出阅读、换一本书再进、杀进程重开，逐格仍处于开启状态。
2. 关闭后同样持久保持关闭。
3. 开启状态下底栏图标始终是功能入口（不变成"退出逐格"）。
4. 点击入口打开设置面板，面板内开关控制开/关。
5. 不满足可用性条件的页面/视图开关保持但不生效，不报错。

## 6. 职责边界

- 不负责分格检测算法本身（既有冻结模块）
- 不负责超分计算本身（仅消费超分产物）
- 不负责条漫连续滚动模式的逐格（仅翻页单页族生效）
- 不改变既有逐格的压暗、分格方式、灵敏度等设置项语义
