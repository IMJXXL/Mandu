# 需求规格：设置 UI 优化

- **需求ID**: REQ-003
- **标题**: 设置偏好 UI 布局与文字排列优化
- **优先级**: P2（中）
- **基线 commit**: eb2ac412
- **状态**: 待评审

## 1. 背景与问题

当前设置偏好相关 UI（阅读设置面板、阅读偏好页、文件夹管理页等）布局与文字排列未经统一规划，存在条目拥挤、文字换行不齐、分组混乱等问题。需要审查并优化布局与文字排列，但必须是纯正向优化，不破坏任何现有功能。

## 2. 核心输入

1. 现有设置页面的布局结构与文字内容
2. 用户对设置项的浏览/修改操作

## 3. 核心输出

1. 优化后的设置页面布局与文字排列
2. 设置项的值变更（行为不变，仅外观优化）

## 4. EARS 需求

### 4.1 布局与文字排列

**REQ-003-A**
WHEN 用户打开任意设置偏好页面 THE SYSTEM SHALL 以审查优化后的布局展示各设置项，分组清晰、条目间距合理、文字排列整齐不溢出换行。

**REQ-003-B**
WHILE 设置页面在任意屏幕宽度（竖屏/横屏/平板）下展示 THE SYSTEM SHALL 保持文字标签简短不挤、不无故截断、不因宽度变化而错乱。

**REQ-003-C**
WHEN 设置项含主标题与副说明文字 THE SYSTEM SHALL 主副文字层级分明（字号/颜色区分），副说明不与主标题混排。

### 4.2 纯正向优化约束

**REQ-003-D**
WHEN 本次 UI 优化执行 THE SYSTEM SHALL NOT 改变任何设置项的语义、取值范围、默认值与持久化键，仅调整布局与文字呈现。

**REQ-003-E**
WHEN 本次 UI 优化执行 THE SYSTEM SHALL NOT 移除任何现有设置项或入口，所有原有可配置能力保持可达。

**REQ-003-F**
WHEN 本次 UI 优化执行 THE SYSTEM SHALL NOT 破坏现有功能的正确性（开关生效、值落盘、跨页/跨;跨进程保持等行为不变）。

### 4.3 约束

**REQ-003-G**
IF 某设置项的文字标签过长 THEN THE SYSTEM SHALL 予以简短化（缩写或精简措辞），避免文字挤在一起或换行，但不得改变该项语义。

## 5. 验收条件

1. 各设置页面布局整齐、分组清晰、文字不溢出/不挤/不乱换行。
2. 竖屏/横屏/平板下设置页均不错乱。
3. 所有现有设置项仍在、仍可配置、仍生效、仍持久化。
4. 无任何设置项被移除或语义被改变。
5. 文字过长者已简短化且语义不变。

## 6. 职责边界

- 不负责新增设置项
- 不负责改变设置项的取值范围或默认值
- 不负责设置项背后的业务逻辑实现
- 仅负责"呈现层"的布局与文字排列优化
